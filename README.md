# Satchel Android — local edition

This branch contains the Kotlin / Jetpack Compose travel journal, packing lists, photos, local travel guide, export and sharing. Travel records and photos remain in private local storage; the app does not provide cloud sync or import.

The online H5, guest authentication, WebSocket, advertisements and subscriptions are removed from this branch. The travel guide uses local, predefined tips. Trip, photo and guide usage no longer depend on membership.

Existing local journal files retain their format. Export a copy before uninstalling or clearing app data; these actions can remove local records. The bundled privacy policy and terms are draft documents and still require operator contact details and review before distribution.

The original online and purchase implementation remains on `master`. This branch has not been built or run as part of the local-only conversion.
